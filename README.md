# DCC

**为 Claude Code 连接自己的模型，用一个面板管理配置、切换模型和查看用量。**

DCC 是运行在电脑上的本地代理，负责在 Claude Code 与模型服务之间转换请求格式，支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic 协议。你可以接入自己有权限使用的模型服务，无需反复手动修改配置文件。

[下载安装包](https://github.com/xiaomo9/Dcc/releases/latest) · [完整使用说明](dcc.md) · [问题反馈](https://github.com/xiaomo9/Dcc/issues)

## 可以做什么

- **管理模型**：填写服务地址、API Key、模型 ID 和协议，直接测试连接。
- **切换模型**：给模型分配编号，在 Claude Code 中选择；拖动排序设置默认模型。
- **控制代理**：查看运行状态，一键启动、重启、停止，或同步 Claude 配置。
- **查看用量**：按模型查看已记录的输入、输出 Token 和调用趋势。统计依赖上游返回的数据，不等同于完整账单。
- **发现新版本**：打开面板时检查更新，也可手动检查并下载安装包。

## 下载与安装

打开 [最新版本下载页](https://github.com/xiaomo9/Dcc/releases/latest)，在 **Assets** 中选择与你的电脑对应的文件：

| 电脑 | 下载文件 | 安装方式 |
| --- | --- | --- |
| Mac，Apple 芯片（M 系列） | `DCC-macOS-arm64.dmg` | 打开 DMG，将 DCC 拖入「应用程序」 |
| Mac，Intel 芯片 | `DCC-macOS-x64.dmg` | 打开 DMG，将 DCC 拖入「应用程序」 |
| Windows，64 位 x64 | `DCC-Windows-x64-Setup.exe` | 双击安装，完成后打开 DCC |

Mac 可在苹果菜单 →「关于本机」查看芯片类型。安装包已经包含 Python 和运行依赖，无需另外安装 Python；下载页中的 `Source code` 是源码，不是安装包。

当前安装包未做开发者签名，系统可能提示安全警告或阻止打开。请确认文件来自本仓库的 Release。

## 第一次使用：三步配置

先准备好模型服务提供方给你的 **服务地址（Base URL）、API Key、模型 ID 和协议**，并确认电脑可以访问该服务。使用 Claude Code 会话需要另行安装 Claude Code；DCC 不附带模型服务或 API 额度。

打开 DCC 后，浏览器会进入配置面板。

1. **添加模型**：进入「模型入口」→「新增模型」，填写连接信息。「section 名称」填一个自己认得的名字，点击「添加到草稿」。可以先「测试连接」，测试可能消耗少量模型用量。
2. **分配编号**：进入「槽位与切换」→「新增槽位」，第一次可填编号 `1`，选择刚添加的模型，再点击「添加到草稿」。槽位就是模型在列表里的编号。
3. **保存使用**：点击页面底部「保存并重载」。保存成功后，确认顶部代理为「运行中」，再重新打开 Claude Code 会话，从模型列表选择对应模型。若代理已停止，先点击「启动代理」。

模型没有出现在 Claude Code 中时，点击「同步 Claude 配置」，然后重新打开会话。面板右上角「使用说明」也提供逐步指引。

## 日常使用

Windows 安装时可勾选「将 dcc 添加到当前用户 Path」，默认不勾选。勾选后重新打开 PowerShell，就能直接使用 `dcc 2`（启动槽位 2）、`dcc list`（查看槽位）和 `dcc status`（查看运行状态）。未勾选或自动配置失败时，安装完成页会显示目录和手动配置提示：打开「编辑账户的环境变量」，在用户 Path 中新增该安装目录，保存后重新打开 PowerShell。使用会话功能前请先安装 Claude Code。

| 想做什么 | 在面板中操作 |
| --- | --- |
| 使用已保存的模型配置 | 点击「启动代理」 |
| 修改地址、密钥或模型 | 编辑后点击「保存并重载」 |
| 更新 Claude 的模型列表 | 点击「同步 Claude 配置」，然后重新打开会话 |
| 重新启动代理 | 点击「重启代理」 |
| 结束 DCC 管理的会话并关闭代理 | 点击「停止全部」 |
| 查看或下载新版 | 点击右上角「检查更新」 |

**保存并重载（有配置变更时）、重启代理和停止全部，会中断已登记的 Claude CLI 会话及代理请求。** 请先结束进行中的工作。启动、重启和同步 Claude 配置使用已经保存的配置，未保存的草稿不会参与。

「同步 Claude 配置」会更新 Claude 用户设置，同时影响普通 `claude` 命令和 VS Code 的 Claude Code 面板。关闭 DCC 启动窗口会关闭配置面板，代理仍可继续运行；需要完全停止时，先点击「停止全部」。

## 更新与配置保存

发现新版本后，下载安装包；保存修改、停止代理及会话、关闭 DCC，再安装新版。**目前需要手动安装，不会静默替换或自动重启。**

安装版配置保存在以下位置，升级使用原有配置，卸载也会保留该目录：

| 系统 | 配置目录 |
| --- | --- |
| macOS | `~/Library/Application Support/DCC/` |
| Windows | `%LOCALAPPDATA%\DCC\` |

首次安装会创建空配置，不会自动导入源码版配置。请勿公开 API Key、配置文件或带访问令牌的面板网址。

## 遇到问题

- **连接测试失败**：核对服务地址、模型 ID、密钥和协议；使用内网服务时，确认办公网络或 VPN 已连接。
- **代理启动失败**：查看面板错误提示，检查配置端口是否被其他程序占用。
- **保存后没有看到模型**：确认已添加槽位，再同步 Claude 配置并重新打开 Claude Code 会话。
- **需要更多帮助**：在 [GitHub Issues](https://github.com/xiaomo9/Dcc/issues) 描述操作步骤、系统和 DCC 版本；附截图前遮挡密钥。也可联系 [aochen0315@163.com](mailto:aochen0315@163.com)。
