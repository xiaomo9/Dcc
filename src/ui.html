操作说明

启动、重启和同步使用磁盘上已保存的配置，未保存的草稿不参与。

停止和重启会中断已登记的 CLI 会话及代理请求，已停止的会话需要手动恢复。代理停止后仍可同步配置、重启代理或停止剩余 CLI 实例；本面板继续运行。

CLI 实例数不包含 VS Code 面板会话。同步配置会更新 Claude 用户设置，完成后需重新打开 Claude 会话。
