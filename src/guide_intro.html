dcc使用说明

QUICK START

第一次使用，从这里开始

保留刚才的配置面板标签页，边看边操作。完成下面三步，就能在 Claude 中选用自己的模型。

✓
开始前，准备一组模型连接信息

向模型服务提供方获取：服务地址（Base URL）、模型 ID、API Key 和协议。不确定填什么时，先向提供模型的同事确认。密钥只填在面板里。

1
模型入口 → 新增模型

把模型加进来

填写你准备好的连接信息。「section 名称」填一个自己认得的名字，然后点「添加到草稿」。

section 名称上游模型 IDBase URL协议API key

可以先点「测试连接」确认能用；测试可能产生少量模型用量。

2
槽位与切换 → 新增槽位

给模型一个编号

槽位号填一个未使用的数字，第一次可以填 1。在「模型入口」中选刚添加的模型，再点「添加到草稿」。

3
页面底部 → 保存并重载

保存，然后打开 Claude

确认保存成功后，重新打开 Claude Code 会话，从模型列表选择刚才编号对应的模型。如果顶部显示代理「已停止」，先点「启动代理」。

保存并重载会中断已登记的终端会话，操作前先结束进行中的工作。

已有模型配置？

不用重复添加。代理停止时点「启动代理」；Claude 模型列表没有显示槽位时，点「同步 Claude 配置」，然后重新打开 Claude 会话。

遇到问题

连接测试失败：核对地址、模型 ID、API Key、协议，并确认已连接模型服务所需网络。

保存后没看到模型：确认槽位已添加；点击「同步 Claude 配置」后重新打开 Claude 会话。
